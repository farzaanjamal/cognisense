Fonts for the app's shell screens (never the task stage).

These are the same fonts the web demo embeds (browser/web/fonts), converted from WOFF2 to TrueType
with fontTools, because Android cannot load WOFF2. The glyphs are unchanged.

- atkinson-hyperlegible-400.ttf, atkinson-hyperlegible-700.ttf: Atkinson Hyperlegible
- noto-nastaliq-urdu-400.ttf: Noto Nastaliq Urdu (bundled so Urdu text is shown in Nastaliq
  even on phones that do not include an Urdu font)
